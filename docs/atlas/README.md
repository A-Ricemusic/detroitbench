# Decision atlas

Edit `chapters/chNN.json` and `meta.json` by hand. `../detroit-decisions.json` is generated by `scripts/atlas-assemble.mjs`; its location is retained because `src/pages/Sources.jsx` references it.

`generated/detroit-decision-flowchart.html` is a standalone page with maintained HTML/CSS/JavaScript and generated `atlas-data` and `story-feed` blocks. `scripts/atlas-embed.mjs` replaces those blocks; do not edit them by hand. The site preparation script copies the page to `public/atlas.html`.

Run `bun run story:assemble`, `bun run atlas:assemble`, then `bun run atlas:build`. `bun run test` checks assembly drift and embedded data against their sources; `bun run build` also refreshes the atlas. See [the documentation map](../README.md) and [AGENTS.md](../../AGENTS.md).
