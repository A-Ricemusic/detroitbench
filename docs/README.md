# Documentation map

Start here to find documentation; see [AGENTS.md](../AGENTS.md) for administering runs, changing the benchmark and validation commands.

| Location | Contents and ownership | Readers |
|---|---|---|
| [chapters/](chapters/README.md) | Hand-written HTML implementation recaps, one per chapter; update with chapter sources | Operators and implementation agents |
| [atlas/](atlas/README.md) | Hand-edited `chapters/` and `meta.json`; `generated/` holds the standalone HTML with generated data blocks | Agents and site build |
| [detroit-decisions.json](detroit-decisions.json) | Generated atlas from `scripts/atlas-assemble.mjs`; retained here because `src/` references this path | Scripts, tests and site build |
| [research/](research/README.md) | Hand-written specifications in `chapters/`; top-level workflow, source inventory and unresolved questions | Research agents, implementation agents and operators; source indexing by site build |
| research/triage/ | Hand-written source checks supporting unresolved questions | Operators and research agents |
| research/operator-notes/ | Independent hand-written replay observations | Operators and agents |
| research/video-leads/ | Hand-written video leads and cross-check notes | Research agents |
| research/video-evidence/ | Captured video evidence and accompanying notes; research artifacts, not build output | Research agents and operators |
| [flowcharts/](flowcharts/README.md) | Original source images and hand-written chapter indexes; never generated by the benchmark | Agents and operators |
| [runs/](runs/README.md) | Generated standalone HTML reports from `scripts/run-report.mjs` | Operators and report readers; site preparation |
| Anthony/ | Operator's personal folder: `analysis/` and `tasks/`; operator-maintained | Operator and agents assigned those tasks |
| design/ | Hand-written UI reference (`slopalytics-reference.md`), referenced by `src/` | UI agents |
| [how-this-benchmark-was-made.md](how-this-benchmark-was-made.md) | Hand-written making-of narrative, paired with the site page and referenced by `src/` | Readers and editorial/UI agents |
| play-along-audit-checklist.md (on demand) | Generated by `scripts/play-checklist.mjs` (`bun run play:checklist`); not committed | Operator |

[Source priority](research/README.md#sources-in-order-of-authority): completed game flowcharts → game text/templates → PowerPyx text, then wiki → tie-break guides → operator observations (subject to the documented reproduced-observation exception).

Generated files are rebuilt from their sources; do not edit generated JSON or embedded data blocks by hand.
