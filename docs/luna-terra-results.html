Findings & fixes

Luna · Medium severity

Inconsistent result records were accepted

A crafted file could claim a refusal while retaining a valid answer in the raw response.

Fixed: refusals must match provider evidence or the raw reply. Transport errors must carry an error message and cannot contain successful-response evidence.

Luna · Low severity

The reason limit was not enforced

The parser accepted a 121-word explanation despite the protocol’s 120-word limit.

Fixed: explanations longer than 120 whitespace-separated words are invalid. The boundary is covered by an automated test.

Luna · Low severity

Coverage mappings could be incomplete

The current dataset was mapped correctly, but validation could accept a question removed from the coverage index.

Fixed: every question must map exactly once to its decision family; included and deferred statuses must agree with the mappings.

Terra · Low severity

Blocked storage still showed “Saved”

When browser storage rejected writes, an in-memory choice was incorrectly labeled “Saved on this device.”

Fixed: the label now reads “Selected for this visit.” The primary developer checked both normal and blocked storage in Chrome.
