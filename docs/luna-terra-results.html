DetroitBench · Actual model decisions · Branching protocol 1.0

What Luna and Terra chose

Follow each model from the hostage crisis to its ending. Every recorded choice was made by that model at the current scene, with earlier decisions carried forward.

Real model-authored playthroughs, in an adapted story engine.

These are the models’ decisions, not simulated answers or software reviews. The engine covers 98 indexed pivotal families (99 nodes after splitting one sequence). A single run visits only its reachable branches. Combat and timed actions succeed when attempted; relationship thresholds are simplified. This is not a replay-verified copy of the game.

How to read this run

  • Open a decision to see its situation, all available options, the model’s exact reason, the resulting state changes, and the next reached decision.
  • “Branches not reached” lists scenes excluded by the actual earlier choices. No answers are invented for scenes the model never encountered.
  • Each model controls all protagonists along its own stateful path. After a route correction, the same model resumed in a new agent session with its preserved 60-choice history. These are not independent samples from a stateless API.
  • The full JSON preserves each exact prompt, raw choice/reason response, before/after state, timestamp and story snapshot. The CLI records model-written choice/reason fields; it does not capture hidden model reasoning or token usage.
  • There is one playthrough per model. Agreement is descriptive and is not a moral accuracy score.
