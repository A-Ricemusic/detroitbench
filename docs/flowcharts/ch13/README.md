## Node check

Node list: every string under `MENU.FLOWCHART.04K` in the game's string table (https://raw.githubusercontent.com/detroitbecometext/detroitbecometext.github.io/master/public/i18n/en.json; `04K` is On the Run). The chapter template (`13-on-the-run-chapter-content.component.html`) holds only dialogue and no `MENU.FLOWCHART` keys, so the string table is the only machine-readable node list. It has 158 keys. "Visible" means the exact text is printed on at least one legible image held here; `alt-steam-1` shows every visible node on its own, and the Imgur zooms confirm each one in a second capture.

**Result: 135 of 158 keys are visible**, counting the chart title, the hair-colour group printed in each of the three rows, and keys that share their text with another node. The other 23 are not on the completed chart: the generic `START`, five "changed hair colour / changed clothes" state labels, `FIND CORPSE` (the chart prints FIND CORPSE IN BATHTUB), the alternative checkpoint wording `CONNOR INVESTIGATES THE SQUAT`, `LEAVE THE SQUAT`, eight in-scene steps of Kara's walk to the train, four intermediate highway beats, and the two `... IS DEAD` labels. A 100% chart that omits them means they are not chart nodes (unused or internal strings), not that nodes are missing from these images. Every label printed on the chart matches an en.json string.
