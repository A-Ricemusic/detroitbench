## Node check

Method: every `MENU.FLOWCHART.02A.K.*` and `MENU.FLOWCHART.02A.M.*` string in the game's string table (https://raw.githubusercontent.com/detroitbecometext/detroitbecometext.github.io/master/public/i18n/en.json) was compared with the legible English images we hold: the `alt-imgur` set, cross-checked against PowerPyx's zooms. The chapter templates (`30.1-crossroads-kara-chapter-content`, `30.3-crossroads-markus-chapter-content`) are dialogue transcripts and do not list chart nodes, so the string table is the only text node list. "Where" gives the `30-crossroads-<character>-alt-imgur-<k>.jpg` numbers.

Matching is by printed name. Some strings are shared by several keys (for example "KARA & ALICE CAPTURED", "MARKUS COLLAPSES", "MARKUS KILLED AND MOST OF JERICHO CAPTURED"). A visible name therefore marks every key that uses it, because the image cannot show which key the game used. Keys marked **No** have no node with that name on either complete chart, English or Chinese. They are most likely unused or cut strings, or alternate labels the chart shows only in other save states (for example `ENDDIED.VALUE` "KARA, ALICE & LUTHER DIED IN THE ASSAULT" against the `NOLUTHER` form the charts show). They are not nodes missing from our images.
