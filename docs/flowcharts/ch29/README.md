Notes on the sources:

- The Steam guide "Detroit: Become Human | 100% Chapter Flowcharts" by StongLory (https://steamcommunity.com/sharedfiles/filedetails/?id=2162781882) has five images for this chapter. They are byte-identical to `alt-imgur-2` to `alt-imgur-6` (same MD5), so they are not stored again. That guide has no whole-chart shot for this chapter.
- The Chinese guide's written notes for this chapter state the trigger for node 28-44b, `无法将地图与其他证物连结` (UNABLE TO LINK MAP TO OTHER EVIDENCE): "取得地图后挂机等待时间结束" (after retrieving the map, idle until time runs out). That agrees with PowerPyx's text (credited to Zin_ZZZ: "Break the statue and wait for time to run out") and its reader comments (Zin_ZZZ, 30 June 2018: "Patch 1.05 fixed the missing map node"). The same notes give Hank's three-way split as Hostile: resigns / is gone; above Hostile up to Neutral: won't help; above Neutral: wants to help; and VISIT GRAVES as requiring Connor to have died in an earlier chapter. These are guide-tier claims, not chart facts.
- Other places checked without finding a better chart: Gamepressure's Last Chance walkthrough (two scene screenshots, no chart), the Fandom wiki chapter page (stub, no chart image), Steam guide 2706070429 (unlabelled set), and Japanese web search (no chart for this chapter).
- What the two 100% charts settle: the whole PowerPyx chart (`-1`) is itself headed `100% COMPLETED`; only PowerPyx's zoom save read 98%. On both 100% charts, `CREATE A DIVERSION` is drawn as a large card but carries no `CHECKPOINT` caption, unlike `START`, `IN THE POLICE STATION` and `IN THE EVIDENCE ROOM`, and the Chinese author numbers it as an ordinary node (19) rather than a Roman-numbered checkpoint. Check this against the research note, which counts it as a checkpoint.

## Node check

Every string under `MENU.FLOWCHART.12C.*` in the game's string table (https://raw.githubusercontent.com/detroitbecometext/detroitbecometext.github.io/master/public/i18n/en.json, fetched 7 November 2026), checked against the English 100% images above. File names drop the `29-last-chance-connor-` prefix.

**Result:** 95 strings (85 node labels, the `FIND JERICHO LOCATION` bracket label and 9 condition tabs); 91 are visible in at least one legible image, and 4 are not drawn on any chart (`TRICKSIMON`, `PERKINSARRIVEAFTERSANDBOXTIMEREND`, `CONNORDIES`, `LOCATION`), which agrees with the research note's list of strings that are not on the chart. No label on any chart is missing from the string table.

**The node PowerPyx's 98% save lacked** is `UNABLE TO LINK MAP TO OTHER EVIDENCE` (`DONTFINDLINKMAPCLUE`), the second row of the map outcome after `RETRIEVE MAP`. According to PowerPyx reader comments it could not be reached until patch 1.05; it reads 0% of players on the post-patch chart. PowerPyx's own `-7` (grey) and `-8` (blue, a different save) already show it, so no chart node was unknown; the new images confirm it inside a 100% chart.
