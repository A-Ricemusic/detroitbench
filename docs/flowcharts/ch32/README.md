**Missing node in PowerPyx's Kara Leaving Detroit (99%).** PowerPyx `leaving-4` was photographed before patch 1.06. It shows a padlocked `[...]` in the lower half of AVOID TEMPERATURE CHECK, between TALK TO LUTHER and TALK TO JERRY. SOURCES.md section 8 records that patch 1.06 removed an unreachable node in exactly this hub. The post-patch charts (Imgur PS4, Chinese guide PC) read 100% with no slot there. In en.json the key between `CONTROLTALKLUTHER` and `CONTROLTALKJERRY` is `CONTROLTALKALICE` = TALK TO ALICE, the only temperature-check label besides SEE ANDROID that no post-patch chart shows. The missing node is therefore almost certainly **TALK TO ALICE** (border hub). This is an inference from position and key order: no image prints the label in that hub. It is cut content, not a node the benchmark should add.

**Kara Captured.** PowerPyx's 83% and padlock came from incomplete saves. The padlocked node in `captured-3` is ALICE FREED BY MARKUS, after KARA LEAVES CAMP WITHOUT ALICE. The post-patch chart has no node beyond what the PowerPyx set and these images show together.
